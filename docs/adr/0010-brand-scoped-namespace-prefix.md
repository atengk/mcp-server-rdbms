# 0010: 采用 atengk-mcp-server- 统一品牌前缀构建多组件生态矩阵

针对 PyPI 全局扁平命名空间中潜在的包名冲突风险，并与作者 GitHub 账号及组织标识 `atengk` 保持高度统一，我们决定统一确立 `atengk-mcp-server-<组件名>` 品牌命名空间前缀标准。本包正式发布名为 `atengk-mcp-server-rdbms`。这不仅 100% 杜绝了命名冲突与仿冒拦截风险，更建立了清晰的官方品牌矩阵心智，方便用户在 Claude Desktop 与 Cursor 中通过统一格式直接拉取后续整个系列工具（如 Redis、Kafka、ES 等）。
