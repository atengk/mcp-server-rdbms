# 0009: 采用语义化 1.0.0 正式版定名与基于 GitHub Actions 的 PyPI 自动化流水线

系统直接以 1.0.0 正式版本发布，对外传递架构成熟与生产就绪信号。全套能力已具备 9 核心工具闭环、AST 静态安全防御、DML 原子事务保障以及 120 个自动化测试验证。在分发工程上，采用由 Git Tag（`v*`）驱动的 GitHub Actions 自动化发布流水线，替代本地手工打包分发。构建前强制执行代码规范与测试全通过门禁，通过 PyPI Trusted Publisher (OIDC) 或安全凭据推送到公网索引，并同步生成包含结构化功能矩阵、快速上手示例与校验和的 GitHub Release 正文。这彻底消除了本地环境脏构建与私钥泄露风险，赋予版本发布完备的透明度与可审计性。
