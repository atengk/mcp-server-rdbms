# 0005: 复杂非标数据类型安全序列化与 BLOB 截断保护

数据库查询返回的结果集经常包含 Python 原生 `json.dumps()` 无法处理的非原生类型（`Decimal`、`datetime`、`UUID`、`bytes`/BLOB 等），直接序列化会引发 `TypeError` 崩溃；而大二进制对象直接输出则可能撑爆 LLM 上下文。我们决定构建专用类型编码器：`Decimal` 转数值或高精度字符、时间转 ISO-8601、`UUID` 转标准串；小于 1KB 的二进制转十六进制，大于 1KB 截断并标注尺寸标记。这彻底保障了数据保真度并建立起防 OOM 安全防护网。
